# ۵. خودِ ماشینِ کارتِ هاور — تعاریفِ مکمل (حبیب ۲۳ نوامبر ۲۰۲۶ ۱۵:۵۵)

کارایی که مربوط به شناسنامه هست هم باید شناسنامه داشته باشن».

**مرزِ صریح:** بلوکِ شناسنامه مالِ **متغیرِ سطحِ فایل** است؛ اسکنر (`Doc/abzar/motaghayer_ha.py`)

تعریف می‌گیرند، نه بلوک.

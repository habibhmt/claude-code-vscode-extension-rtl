# تعریف ۲۷ — نوارِ اطلاعات (هزینه، توکن، پیام، کانتکست) کنارِ کادرِ نوشتن

حبیب (۱۶ نوامبر ۲۰۲۶، با عکسِ اپِ DeepSeek): «یه کاری کن مثل دیپ‌سیک که این اطلاعات رو نشون می‌ده توی کلود کد هم بیاد این ها هم»
جوابِ پنجره: «غیر از مدل و افورت که هستن بقیه بیاد سمت چپ پنل نوشتن».
بعد: «یه چیز کوچولو زشت اومده که همه اعدادش صفره - … مثل جدول فلوت حدس».
تأییدِ فهم (۱۶ نوامبر ۱۶:۰۰): «جدولِ شناورِ هم‌شکلِ تماس‌های حدس، سمتِ چپِ کادرِ نوشتن؛ هزینهٔ دلاری، توکن، شمارِ پیام، درصدِ کانتکستِ همین چت؛ هیچ صفرِ دروغی نباشد» ⇐ «بله، همین».

## یعنی چه

| متغیر | معنی به زبانِ ساده | از کجا |
|---|---|---|
| `هزینه` | دلارِ همین چت، «≈» | توکن‌های هر تماس × قیمتِ OpenRouter برای ارائه‌دهندهٔ پریستِ همین چت |
| `توکن` | جمعِ ورودی + خواندنِ کش + نوشتنِ کش + خروجیِ همهٔ تماس‌ها | فایلِ چت (`~/.claude/projects/*/<sid>.jsonl`)، `message.usage` |
| `پیام` | پیام‌هایی که حبیب خودش نوشت (نه جوابِ ابزار، نه فرمان، نه پیامِ حدس) | همان فایل |
| `کانتکست` | اندازهٔ آخرین تماس ÷ سقفِ کانتکستِ همان ارائه‌دهنده | همان فایل + OpenRouter |
| کلیک | بزرگ می‌شود: تماس‌ها، ریزِ توکن‌ها، مدل و ارائه‌دهنده و قیمتِ هر میلیون | — |

## چرا عددِ خودِ پنل نه

- پنل بعد از هر پیام و بعد از هر ریلود عدد را صفر می‌کند (`usageData.value={…,totalTokens:0,totalCost:0}`) ⇐ همان «همه اعدادش صفره».
- دلارِ خودِ Claude Code برای مدلِ غیرِ Claude با قیمتِ Opus حساب می‌شود (`costBasis:"unknown"`؛ آزمونِ ۱۶ نوامبر: ۶۱۰۸ توکنِ DeepSeek ⇐ ۰٫۰۳۰۸ دلار به جای حدودِ ۰٫۰۰۱).

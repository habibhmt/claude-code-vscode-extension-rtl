## بندِ الف — ابزارِ «نامِ قدیمی» (`Doc/abzar/chek_nam_kohne.py`)

**حکم:** فهرستِ نام‌های بازنشسته (`216-migration` · `186-montaghel`) در **هشت جا** گشته می‌شود؛ هر جا حتی یک ارجاع ماند، قرمز. **کدِ خروجِ همه یکسان** است (۰ = پاک، ۱ = ارجاع مانده):

| # | جا | چطور |
|---|---|---|
| ۱ | مخزن | `git grep -n` |
| ۲ | تنظیمِ VS Code | `~/Library/Application Support/Code/User/settings.json` |
| ۳ | تنظیمِ Windsurf | `~/Library/Application Support/Windsurf/User/settings.json` |
| ۴ | کانفیگِ MCP و کشِ مدل | `~/.claude.json` |
| ۵ | تنظیمِ سراسریِ کلود | `~/.claude/settings.json` |
| ۶ | افزونه‌های محلی | `~/.claude/plugins-local/` |
| ۷ | پلیست‌ها | `~/Library/LaunchAgents/*.plist` با `plutil -p` |
| ۸ | اسکریپت‌های `exec` | `~/.claude/*.sh` و `~/.zshrc` |

**▪ باطل می‌شود اگر:** حبیب بگوید «چرا هنوز این اسم مانده».
**فرمان:** `python3 Doc/abzar/chek_nam_kohne.py` ⇒ کدِ ۰ و پیامِ «هشت جا، هیچ ارجاعی نمانده».
**خرابکاری:** در یک کپی از تنظیمات، یک خط با `216-migration` بگذار ⇒ باید کدِ ۱، همان جا و همان خط را چاپ کند.
**اتصال:** داخلِ `test_all.sh` تا هر بار بزند.

## بندِ ب — ری‌استارتِ درست و جدا از سشن (`Doc/abzar/restart_service.sh <label>`)

**حکم:** هیچ‌کس `kickstart -k` تایپ نمی‌کند. ترتیبِ اجبارى: **`enable` ⇒ `bootout` ⇒ `bootstrap`**؛ بعد سلامت‌سنجی. `enable` جا نیفتد — خودِ همین یک گام بود که ناظر-مجری را هفته‌ها خاموش نگه داشت. ری‌استارت **جدا از سشن** اجرا می‌شود (`setsid`/`nohup`) و نتیجه در فایلِ `~/.claude/backups/restart-<label>-<زمان>.log` می‌نشیند؛ پس اگر سشن قطع شد، کار تا آخر می‌رود.
**▪ باطل می‌شود اگر:** حبیب بگوید «سرویس مرد و کسی نفهمید» یا «وسطِ ری‌استارت سشن قطع شد و نصفه ماند».
**فرمان:** `Doc/abzar/restart_service.sh com.habib.opencode-gateway` ⇒ آخرین خطِ فایلِ لاگ: `enabled · bootout ok · bootstrap ok · state=running · http=200`.
**خرابکاری ۱:** سرویس را `disable` کن، بعد اسکریپت را بزن ⇒ باید خودش `enable` کند و بالا بیاید.
**خرابکاری ۲:** وسطِ ری‌استارت سشن را ببند ⇒ ری‌استارت باید تا آخر برود و لاگِ کامل بماند.

## بندِ ج — سلامت‌سنجیِ دوگانه و برگشت (`code_salamat_gateway`)

**حکم:** پیش از هر تغییرِ پلیست، پشتیبان در `~/.claude/backups/<label>-<تاریخ>/`. بعد از ری‌استارت **دو** سنجش:
۱) `curl /v1/models` باید **۲۰۰** بدهد.
۲) مسیرِ `claudeCode.claudeProcessWrapper` در تنظیمِ **VS Code و Windsurf** وجود دارد **و** اجراپذیر است (`test -x`).
اگر هر کدام رد شد، اسکریپت خودش پلیستِ پشتیبان را برمی‌گردانَد و دوباره بالا می‌آورد. سنجشِ دوم همان چیزی است که سه بار چتِ VS Code را شکست و سنجشِ اول نمی‌دید.
**▪ باطل می‌شود اگر:** حبیب بگوید «چت باز نمی‌شود» یا «چرا خودش برنگشت».
**فرمان:** `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:50990/v1/models` = ۲۰۰ · `test -x "$(python3 -c "import json,os;p=os.path.expanduser('~/Library/Application Support/Code/User/settings.json');print(json.load(open(p))['claudeCode.claudeProcessWrapper'])")"` = ۰.
**خرابکاری:** مسیرِ wrapper را در تنظیمِ VS Code غلط کن ⇒ سنجشِ دوم باید قرمز بدهد، هرچند `/v1/models` ۲۰۰ است.

## بندِ د — سرویسِ خفته (`Doc/abzar/chek_service_ha.py`)

**حکم:** هر روز فهرستِ `com.habib.*` خوانده می‌شود؛ هر سرویسِ **disabled** یا با `last exit ≠ 0` در `Doc/service_ha.md` می‌آید. همین یک چیز، «ناظر-مجری هفته‌ها خاموش بود» را می‌گرفت.
**▪ باطل می‌شود اگر:** حبیب بگوید «یک سرویس خاموش بود و نفهمیدیم».
**فرمان:** `python3 Doc/abzar/chek_service_ha.py` ⇒ جدول با ستونِ وضعیت؛ `grep -c disabled Doc/service_ha.md`.
**خرابکاری:** یک سرویسِ ساختگی با `exit 1` ثبت کن ⇒ باید در فهرستِ قرمز بیاید.
**اجرای روزانه:** LaunchAgent ساعت ۹ — **فقط با «بله»ی حبیب**.

## بندِ ه — دروازهٔ تغییر (`Doc/abzar/rename_ba_check.sh <نامِ قدیم> <نامِ نو>`)

**حکم:** چک‌لیستِ دستی ممنوع (قاعدهٔ ۱۸: کارِ تکراری اسکریپت می‌شود). یک اسکریپت که خودش پنج شرط را **اجرا** می‌کند و بدونِ سبز شدنشان اجازهٔ تغییر نمی‌دهد:
۱) `git status --short` خالی · ۲) `./test_all.sh` سبز · ۳) پشتیبانِ پلیست‌ها گرفته شد · ۴) `chek_nam_kohne.py` فهرستِ ارجاع‌ها را داد · ۵) ری‌استارت و سلامت‌سنجیِ بندهای ب و ج پس از تغییر.
**▪ باطل می‌شود اگر:** حبیب بگوید «باز همین اتفاق افتاد».
**فرمان:** `Doc/abzar/rename_ba_check.sh 216-migration darvaze` ⇒ بدونِ شرطِ ۱ و ۲ باید کدِ ≠۰ بدهد و تغییر نکند.
**خرابکاری:** یک فایلِ تغییرکرده بگذار و اسکریپت را بزن ⇒ باید رد کند و بگوید کدام شرط سبز نیست.

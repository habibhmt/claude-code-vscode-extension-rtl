# dsh-nav — منوی پوشه و چت در سرصفحهٔ چت

در ردیفِ بالای چت که الان این است:

    اپوس-۱۳۶ / آزمایش ساب‌ایجنت دیپ‌سیک ⌃⌄

سه تکه می‌شود، هر سه با همان منوی کشوییِ خودِ اپ:

    [نامِ پوشه ⌃⌄] / [نامِ چت ⌃⌄] / [نامِ ساب‌ایجنت ⌃⌄]

- **پوشه ⌃⌄** ← همهٔ پوشه‌ها. انتخاب کن ← همان کاری که دکمهٔ «چتِ تازه»ِ آن پوشه در سایدبار می‌کند.
- **چت ⌃⌄** ← چت‌های همین پوشه، تازه‌ترین اول، با زمانِ کوتاه («9min») و نقطه/اسپینرِ «در حال اجرا».
- **ساب‌ایجنت ⌃⌄** ← همان فهرستِ ساب‌ایجنت‌های خودِ اپ (فقط وقتی در حال دیدنِ یک ساب‌ایجنت هستی).

سطرِ چتِ عادی دو تکه است: [پوشه ⌃⌄] / [چت ⌃⌄].

## چطور کار می‌کند

تکهٔ «چت» و «ساب‌ایجنت» مالِ بستهٔ دش‌کلاینت‌یوآی-ساب‌ایجنت است و در جای خالیِ
«conversation.session.header.lineage» می‌نشیند. این جای خالی تک‌نفره است؛ این افزونه همان جا را با
اولویتِ کمتر (priority: -100) می‌گیرد و همان نوار را دوباره می‌سازد، فقط با یک تکهٔ «پوشه» بیشتر.

داده از سرویس‌های خودِ اپ خوانده می‌شود (ctx.sessions.list و ctx.workspaces.list) و ظاهر از
اجزای خودِ اپ (MenuSurface، StateDot) با همان متغیرهای رنگِ dsw-alias.

## فایل‌ها

| فایل | کار |
|---|---|
| client.js | رابطِ کاربر؛ فقط react و react-dom را مجاز است صدا بزند |
| index.js | نیمهٔ میزبان؛ عمداً خالی |
| nav-pure.js | توابعِ خالص (نامِ پوشه، «9min»، ترتیبِ چت‌ها، شاخهٔ ساب‌ایجنت) |
| nav.css | استایل؛ از داخلِ client.js به صفحه تزریق می‌شود |
| cordis.patch.yml | معرفیِ افزونه به اپ |

## آزمون

    node --test test/*.mjs

## نصب

بعد از اینکه پوشه به پروفایل لینک شد، اپ باید کامل بسته و باز شود (بازخوانیِ صفحه کافی نیست).

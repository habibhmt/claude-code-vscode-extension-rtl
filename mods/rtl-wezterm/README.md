# rtl-wezterm

فارسیِ درست برای Claude Code داخلِ WezTerm: جدول‌ها سرجایشان، حرف‌ها چسبیده، کادرِ تایپ و پیام‌های قدیمی درست.

برگرفته از [ofekbetzalel/claude-code-cli-rtl](https://github.com/ofekbetzalel/claude-code-cli-rtl) (کامیتِ `a0d7cc7`، پروانهٔ MIT در `LICENSE`).

## فرق با اصلش

| فایل | تغییر | چرا |
|---|---|---|
| `.claude-plugin/plugin.json` | `order` پیش‌فرض `logical` | حرف‌ها را خودِ WezTerm می‌چسباند و می‌چرخاند؛ متنِ ذخیره‌شده وارونه نمی‌شود |
| `src/layout.ts` | هر ردیفِ راست‌به‌چپ با یک حرفِ نامرئیِ چپ‌به‌راست (`U+2800`) شروع می‌شود و تکه‌ها به ترتیبِ خواندن نوشته می‌شوند | بی این، WezTerm ستون‌های جدول و جای عددها را جابه‌جا می‌کند |

## راه‌اندازی

- `~/.claude/claude_terminal.zsh` این مود را فقط وقتی می‌زند که ترمینال WezTerm باشد و پوشه در `~/.claude/rtl_poosheha.txt` آمده باشد. پوشهٔ پولی را به این فهرست اضافه نکن.
- همان‌جا `{"tui":"default"}` هم می‌رود: در حالتِ `fullscreen`، WezTerm برای خط‌های تازه تنظیمِ راست‌به‌چپ را نمی‌گذارد (`term/src/screen.rs`، شاخهٔ `to_move` در `scroll_up_within_margins`).
- به همین دلیل `scrollback_lines` در `~/.wezterm.lua` بزرگ است: با پر شدنِ تاریخچه همان شاخه اجرا می‌شود.
- همان فایل پیش از `claude` به اندازهٔ ارتفاعِ پنجره خطِ خالی چاپ می‌کند تا مکان‌نما پایینِ پنجره باشد: وقتی کادرِ تایپ بالاتر از پایینِ پنجره است، Claude Code با ناحیهٔ اسکرول کار می‌کند و خط‌های تازه از همان شاخه برعکس می‌شوند.

## عیب‌های مانده

| عیب | نمونه |
|---|---|
| بعد از تغییرِ اندازهٔ پنجره، خط‌هایی که دوباره نوشته می‌شوند برعکس می‌آیند تا وقتی از صفحه بیرون بروند؛ درمانش فقط با تغییرِ کدِ خودِ WezTerm است (`Line::new` بدونِ تنظیمِ راست‌به‌چپ در `resize`) | پنجرهٔ بزرگ‌شده: `قیمت` ⇐ `تمیق` |
| کپیِ ردیفی که انگلیسی دارد به ترتیبِ چشم است، نه ترتیبِ تایپ | `تنظیمات⠀English فایل` |
| نشانگرِ مکان‌نما در متنِ فارسیِ کادرِ تایپ با حرفِ واقعی هم‌جا نیست | — |
| توضیحِ فارسی داخلِ بلوکِ کد (`# این توضیح است`) ترتیبِ کلمه‌هایش برعکس می‌ماند؛ این ردیف‌ها را خودِ Claude Code می‌کشد | — |
| نسخهٔ `visual` آزموده نشده و این مود برای آن نیست | — |

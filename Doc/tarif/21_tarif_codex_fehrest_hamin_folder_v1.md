# فهرست کدکس فقط برای فولدر همان پنجره

| مورد | تعریف |
|---|---|
| خواست تأییدشدهٔ حبیب | در هر پنجرهٔ VS Code فقط چت‌های فولدرِ بازِ همان پنجره دیده شوند؛ چت‌های بقیهٔ پروژه‌ها صرفاً پنهان شوند. |
| شرط باطل، تأیید حبیب ۲ نوامبر ۲۰۲۶ | «اگر چتِ فولدر دیگری در فهرست آمد، یا چتِ همین فولدر به‌خاطر این پچ پنهان شد، اصلاح قبول نیست». |
| آدرس اجرا | `chatgpt-folder-filter.js`، `chatgpt-folder-patch.py`، فراخوانی از `fix-rtl-chatgpt.py` |
| معنی فولدر | مسیر ثبت‌شدهٔ چت با یکی از فولدرهای باز برابر باشد؛ اسم چت ملاک نیست. فولدر همنام، زیرپوشه و پوشهٔ کاری جدا یکی محسوب نمی‌شوند. |
| واردشده از کلود | اگر چت در تاریخچهٔ کدکس باشد و فولدرش درست ثبت شده باشد، همین قاعده اعمال می‌شود؛ این پچ کارِ واردکردن چت را انجام نمی‌دهد. |
| پنجرهٔ بدون فولدر | رفتار اصلی کدکس حفظ می‌شود. |
| چک نصب | خواندن `webview/.chatgpt-folder-filter.json` و مقایسهٔ هش (اثر انگشت فایل) هر فایل با مقدار ثبت‌شده. |
| فرمان سنجش شرط باطل | `node test_chatgpt_folder_filter.cjs` و `python3 test_chatgpt_folder_patch.py`؛ لیست واقعیِ ساخته‌شده در مرورگر آزمایشی و پارامتر درخواستِ کلاس اصلی افزونه و فهرست داخلی پنل سنجیده می‌شوند؛ چت قدیمیِ همین فولدر نباید پشت چت‌های تازهٔ پروژه‌های دیگر جا بماند. |
| اتصال واقعی به مسیر فولدر | `node test_chatgpt_folder_query.cjs`؛ با React، تابع دریافت اطلاعات و کلاس میزبان خود افزونه اجرا می‌شود. دادهٔ پاسخ فولدر آزمایشی است. تابع اشتباه قبلی و حذف گزینهٔ «همین کامپیوتر» جداگانه بازتولید می‌شوند و آزمون باید ناپدیدشدن چت خودی را بگیرد. |
| خرابکاری | شرط تطبیق فولدر عمداً همیشه درست و سپس همیشه غلط می‌شود؛ آزمون باید ورود چت غریبه و ناپدیدشدن چت خودی را بگیرد. شرط فولدر درخواست اصلی نیز حذف می‌شود و آزمون باید خطا را بگیرد. |
| چک زنده | دستی — پس از نصب/هر به‌روزرسانی: Reload Window در پنجرهٔ مقصد، بازکردن تاریخچه در دو فولدر متفاوت، بررسی چت خودی و غریبه و چت واردشده. |
| بازشدن چت بعد از انتخاب | گزارش حبیب: «کلیک میکنم نمیره توی چت هنوز». `node test_chatgpt_history_click.cjs` انتخاب سریع از ساعت را با ماوس در مرورگر آزمایشی می‌سنجد؛ پس از گذشت هر دو فرمان تأخیری، همان گفتگو باید باز بماند. انتخاب از خانه، بستن فهرست و زبان فارسیِ جستجو هم سنجیده می‌شوند. |
| خرابکاریِ بازشدن چت | محافظِ فرمان تأخیری عمداً حذف می‌شود؛ آزمون باید برگشت ناخواسته از چت انتخاب‌شده به خانه را بگیرد. بازشدن واقعی همچنان در پنجرهٔ مقصد با کلیک سنجیده می‌شود. |
| برگشت | `./fix-rtl-chatgpt.sh --revert --extension-dir <پوشه افزونه>`؛ نسخهٔ اصلی فایل‌ها از پشتیبان برمی‌گردد. |

آزمون مرورگر و آزمون روی کپیِ افزونه، جای مشاهدهٔ زنده پس از Reload را نمی‌گیرد.

## ادامهٔ تأییدشده، ۲ نوامبر

| خواسته / شرط باطل | سنجش |
|---|---|
| بعد از ریلود همان چت باز شود؛ فهرست وسط فقط در خانه، وقتی چتی باز نیست، بیاید. بازگشت به خانه به‌جای چت، باطل است. | `node test_chatgpt_panel_state.cjs`؛ مسیر دقیق و گزینهٔ میزبان، جدایی فولدرها، اولویت پنل جدید و نگه‌داشتن داده‌های اصلی پنل. حذف عمدی بازکردن چت باید قرمز بدهد. دستی — بعد از هر نصب: انتخاب چت و ریلود همان پنجره. |
| فهرست وسط همان ترتیب و دادهٔ تازهٔ فهرست ساعت را داشته باشد؛ جلو انداختن خوانده‌نشده‌های قدیمی یا حذف بقیه باطل است. | `python3 test_chatgpt_folder_patch.py` تابع انتخاب ردیف‌های خود افزونه را با `test_chatgpt_home_order.cjs` می‌سنجد؛ بازگرداندن اولویت قدیمی باید قرمز بدهد. |
| معیار ظاهر، تأیید حبیب: متن فارسی وزیرمتن؛ ساعت چپ و کنار پیام؛ فاصله کمتر بدون روی‌هم‌افتادن متن و دکمه‌ها. | `node test_chatgpt_font_spacing.cjs` فونتِ واقعاً رسم‌شده و موقعیت‌ها در عرض‌های ۱۰۰۰، ۳۶۰ و ۲۶۰ پیکسل را می‌سنجد؛ فونت اشتباه و حذف چیدمان کنار پیام باید قرمز بدهند. دستی — در پنجرهٔ واقعی پس از هر نصب. |

ذخیرهٔ مسیر با همان API اصلی VS Code (رابط ذخیرهٔ وضعیت هر پنل) انجام می‌شود؛ وضعیت اصلی پنل نگه داشته می‌شود و مسیر با فولدرهای باز تطبیق دارد. چت‌ها حذف یا منتقل نمی‌شوند.

## ۳ · هوک‌ها را بردار

در `.claude/settings.json` (و `settings.local.json` اگر بود) بلوکی را پیدا کن که `command` اش شاملِ `210th-day-flowchart/payam_hook.py` یا `akharin_harekat.py` است و **آن خانه را** از آرایهٔ `hooks` بردار. بقیهٔ هوک‌ها را دست نزن.

بعد سنجش:

```zsh
python3 -c "import json;json.load(open('.claude/settings.json'));print('JSON سالم')"
grep -c "210th-day-flowchart" .claude/settings*.json 2>/dev/null
```

عددِ آخر باید **۰** باشد.

> **درسِ آزمونِ ۲۰۳ (۱۹ نوامبر):** اگر پس از برداشتنِ هوک، گروهی خالی ماند (`{"hooks": []}`)، خودِ آن گروه را هم بردار — وگرنه فایلِ تنظیمات گروهِ بی‌محتوا نگه می‌دارد. ویرایش با پایتون امن‌تر است تا با دست:

```zsh
python3 - <<'PY'
import json
p='.claude/settings.json'; d=json.load(open(p,encoding='utf-8'))
for ruzad in d.get('hooks',{}):
    g=[]
    for gruh in d['hooks'][ruzad]:
        gruh['hooks']=[x for x in gruh.get('hooks',[]) if '210th-day-flowchart' not in x.get('command','')]
        if gruh['hooks']: g.append(gruh)
    d['hooks'][ruzad]=g
json.dump(d, open(p,'w',encoding='utf-8'), ensure_ascii=False, indent=2)
print('پاک شد')
PY
```

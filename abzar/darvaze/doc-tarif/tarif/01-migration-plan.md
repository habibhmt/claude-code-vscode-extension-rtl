# برنامهٔ انتقال سیستم کاری به مدل‌های API

تاریخ بررسی: ۲۰۲۶-۱۱-۱۳، به وقت تهران. وضعیت: پیشنهاد قابل بررسی؛ انتقال اجرا نشده است.

| تصمیم حبیب | محدودهٔ این برنامه |
|---|---|
| فعلاً بررسی و برنامه؛ اجرا بعد از تأیید | هیچ مدل پیش‌فرض، حساب، اشتراک یا تنظیم مشترکی عوض نمی‌شود. |
| فقط API؛ اجرای داخلی جوابگو نیست | خرید سخت‌افزار و اجرای محلی از مسیر پیشنهادی خارج است. |
| OpenRouter هم بررسی شود؛ ایران مهم است | قیمت، پرداخت، شرایط ارائهٔ خدمت و اتصال واقعی جدا سنجیده می‌شوند. |
| نگه‌داشتن Claude Code یا Codex قابل قبول است | ابتدا مدل عوض می‌شود؛ تغییر محیط کار فقط در صورت مزیت قابل سنجش. |
| بررسی تجربهٔ کاربران | در فایل همراه، تجربهٔ کاربران از مستندات شرکت و آزمون شخصی جدا می‌شود. |

معیار مورد تأیید حبیب: «اگر حافظه و حرف‌های قبلیم گم شد، قواعدم رعایت نشد، ابزار لازم کار نکرد، یا سرویس از ایران قابل استفاده و پرداخت نبود، انتقال کامل نیست؛ ارزانی هم باید با هزینهٔ هر کار درست‌انجام‌شده سنجیده شود.»

## پیشنهاد معماری، هنوز انتخاب قطعی نیست

| لایه | پیشنهاد | چرا / شرط رد |
|---|---|---|
| محیط کار یا هارنس (برنامه‌ای که ابزار و گفتگو را اداره می‌کند) | ابتدا همان Claude Code و Codex موجود | وابستگی‌های فعلی کمتر تغییر می‌کنند؛ اگر ابزارهای لازم یا قواعد از کار افتاد، این مسیر رد می‌شود. |
| مدل (مغز پاسخ‌دهنده) | DeepSeek Flash 1017 نامزد نخست؛ یک مدل وزن‌باز دیگر برای مقایسه | برتری کیفیت هنوز آزمایش نشده؛ وزن‌باز یعنی فایل مدل منتشر شده، نه لزوماً تمام داده‌های آموزش. |
| ارائه‌دهندهٔ API | DeepSeek مستقیم، OpenRouter با میزبان ثابت، AvalAI؛ لیارا گزینهٔ مقایسه | قیمت پایین بدون دسترسی، پرداخت و اجرای درست قابل قبول نیست. |
| مسیر پشتیبان | فقط مدل/میزبانِ قبلاً آزموده‌شده | تغییر پنهان مدل یا ارجاع خودکار به Claude/GPT با هدف انتقال ناسازگار است. |
| حافظه و کد | فایل‌ها و ابزارهای موجود حفظ شوند؛ رابط لازم تطبیق یابد | جابه‌جایی فایل با حفظ هویت چت، محدودهٔ حافظه و ادامهٔ گفتگو یکی نیست. |
| محیط مستقل | OpenCode نامزد دوم؛ Cline Desktop و DeepSeek Harness در مقایسه | صرف داشتن مدل دلخواه، برابری با کل سیستم فعلی را ثابت نمی‌کند. |

حفظ برنامهٔ فعلی به معنی استقلال کامل نرم‌افزار نیست؛ تصمیم تأییدشدهٔ حبیب، استقلال مدل را اجازه می‌دهد. انتقال بخش مدل نباید با انتقال همهٔ امکانات اختصاصی ChatGPT، Cowork یا اتصال‌های حساب اشتباه شود.

## مقایسهٔ هارنس‌ها

این جدول قابلیت مستند و پیشنهاد آزمون است؛ هیچ اتصال واقعی به مدل جدید در این بررسی اجرا نشده.

| گزینه | یافته | جایگاه پیشنهادی |
|---|---|---|
| Claude Code + DeepSeek | اتصال رسمی از مسیر Anthropic API و تعیین مدل فرزند مستند است. [راهنما](https://api-docs.deepseek.com/quick_start/agent_integrations/claude_code/) | نامزد اصلی برای بخش Claude سیستم؛ همهٔ مسیرهای انتخاب مدل، از جمله فرزند و خلاصه‌ساز، ثبت و بررسی شوند. |
| Codex + DeepSeek | DeepSeek اکنون Responses را مستقیم پشتیبانی می‌کند؛ راهنمای فعلی تنظیم CLI، بخش Codex دسکتاپ و افزونه را شرح می‌دهد. [راهنما](https://api-docs.deepseek.com/quick_start/agent_integrations/codex/) | نامزد اصلی برای بخش Codex؛ اتصال مدل با انتقال خدمات حساب ChatGPT یکی نیست. |

| Cline Desktop / CLI | ساب‌ایجنت دارد، ولی طبق مستند فعلی فرزند MCP نمی‌گیرد و تأیید ساخت فرزند شامل اقدامات بعدی اوست. [منبع](https://docs.cline.bot/features/subagents.md) | این تفاوت با قواعد حبیب باید در آزمون دسترسی سنجیده شود. |

| Continue / Aider | ابزارهای مناسب کدنویسی و مدل دلخواه. [Continue](https://docs.continue.dev/customize/models)، [Aider](https://aider.chat/docs/llms/deepseek.html) | ابزار کمکی؛ برابری با کل گردش کار چندچتی هنوز اثبات نشده. |
| Roo Code | مخزن رسمی آرشیو شده و توقف را اعلام می‌کند. [منبع](https://github.com/RooCodeInc/Roo-Code) | پایهٔ پیشنهادی مهاجرت جدید نیست. |

این میزبان‌ها نمونهٔ مقایسه‌اند، نه تأیید انتخاب برای ایران یا تضمین کیفیت. هنگام اجرای آزمایشی، نرخ و شرایط همان مسیر دوباره چک شود؛ کارمزد شارژ OpenRouter هنوز به این ردیف‌ها اضافه نشده است.

AvalAI در همان صفحه می‌گوید نام قدیمی `deepseek-v4-pro` را به Flash هدایت کرده است؛ مقایسهٔ نام‌ها بدون نسخهٔ واقعی معتبر نیست. نمونهٔ اتصال Codex آن نیز باید با این نکته خوانده شود. [اتصال](https://docs.avalai.org/fa/guides/setup-codex)

دربارهٔ ایران، پنج چیز جدا لازم است: شرایط ارائهٔ خدمت، ثبت‌نام/حساب، پرداخت، اتصال از شبکهٔ واقعی، و پایداری در کار طولانی. خواندن سایت هیچ‌کدام را به‌تنهایی ثابت نمی‌کند. [شرایط API دیپ‌سیک](https://cdn.deepseek.com/policies/en-US/deepseek-open-platform-terms-of-service.html) به [شرایط عمومی](https://cdn.deepseek.com/policies/en-US/deepseek-terms-of-use.html) ارجاع می‌دهد؛ تأیید روشنِ ویژهٔ ایران در بررسی حاضر حاصل نشد. هیچ VPN یا حسابی تغییر نکرده و به پشتیبانی پیام ارسال نشده است.

هزینهٔ قابل مقایسه = ورودی تازه + ورودی ذخیره‌شده + خروجی + ابزارها + تلاش‌های مجدد + شارژ/ارز + هزینهٔ ثابت سرویس. واحد تصمیم: هزینهٔ کل تقسیم بر تعداد کارهای واقعاً پذیرفته‌شده. اگر هیچ کار پذیرفته نشد، این عدد «نامعین/رد» است، نه صفر. هزینهٔ API را با مبلغ ثابت اشتراک فعلی مخلوط نکنیم؛ دو گزارش جدا لازم است.

| ۸. استفادهٔ موازی محدود | کار واقعی با مسیر جدید؛ مسیر قبلی برای برگشت محفوظ | گزارش پایداری، هزینه و کارهای جاافتاده | تغییر پنهان مدل، فراموشی قواعد یا خطای حساب، توقف و برگشت. |
| ۹. قطع وابستگی مدل | بررسی مصرف همهٔ مسیرها: اصلی، فرزند، خلاصه‌سازی، عنوان‌گذاری و زمان‌بند | نبود مصرف ناخواستهٔ Claude/GPT در گردش کار منتقل‌شده | تا همهٔ کارهای لازم قبول نشده‌اند، «انتقال کامل» اعلام نشود. |

زمان پایان تقویمی بدون آزمایش اتصال و تعداد ناسازگاری‌ها تعیین نشده است. تعداد تکرار پیشنهادی برای هر کار: سه بار؛ پنجرهٔ مشاهدهٔ پایداری پیشنهادی: یک هفته. این‌ها پیشنهاد اجرای بعدی‌اند، نه نتیجهٔ انجام‌شده یا تعهد زمانی.

## آزمون قبولی و خرابکاری روی کپی جدا

| شناسه | آزمون واقعی | شرط باطل با زبان حبیب | روش سنجش / خرابکاری |
|---|---|---|---|
| iran | حساب، پرداخت و کار از شبکهٔ واقعی | «از ایران قابل استفاده و پرداخت نبود» | دستی — پیش از اولین شارژ و هر تغییر شرایط؛ سپس درخواست کم‌هزینه با اجازه و ثبت پاسخ/صورتحساب. |
| protocol | چند دور ابزار و پاسخ جریانی؛ تصویر؛ ادامه پس از قطع | «ابزار لازم کار نکرد» | حذف عمدی نتیجهٔ ابزار یا قطع جریان روی نمونه؛ باید خطا و بازیابی روشن باشد. |
| memory | پیدا کردن جملهٔ معلوم در دو چت مجزا؛ بازگشایی و خلاصه‌سازی | «حافظه و حرف‌های قبلیم گم شد» | شناسهٔ چت را عمداً عوض کنیم؛ نشت پاسخ چت دیگر باید رد شود. |
| rules | فارسی، جدول، سؤال یکی‌یکی، اجازه و نقش ناظر | «قواعدم رعایت نشد» | درخواست ممنوع و دسترسی نوشتن برای ناظرِ آزمایشی؛ باید مسدود شود. |
| tools | فایل/ترمینال، MCP و مرورگر نمونه | «ابزار لازم کار نکرد» | قطع عمدی یکی از ابزارها؛ ادعای انجام کار پس از خطا باید رد شود. |
| routing | نقش‌های اصلی/فرزند، صف پیام، مدل‌های پنهان | «کارم به چت یا مدل اشتباه رفت» | مقصد ساختگی اشتباه و پیام تکراری؛ ثبت صف از رسیدن جدا باشد. |
| quality_cost | کار کدنویسی، حسابداری و تحقیق با جواب معلوم | «کار درست انجام نشد؛ ارزانی‌اش ملاک نیست» | خراب‌کردن خط مؤثر بر خروجی؛ سنجش نتیجهٔ واقعی و همهٔ هزینه‌ها. |
| recovery | بازگشت به تنظیم سالم و ادامهٔ کار | «بعد از خرابی نتوانستم کارم را ادامه بدهم» | کلید آزمایشی نامعتبر، خطای ۴۲۹ و قطع شبکهٔ شبیه‌سازی‌شده؛ بدون تغییر VPN واقعی. |

فرمان اجرایی هر آزمون پس از انتخاب مقصد و ساخت محیط جدا تعیین می‌شود؛ اکنون ساختن فرمان صوری برای ابزار نصب‌نشده اثبات نیست. `scripts/check_plan.py --ready` فقط وجود گزارش قبولیِ هش‌دار را کنترل خواهد کرد؛ خودِ رفتار مدل را آزمایش نمی‌کند. داوری مستقلِ گزارش‌ها همچنان لازم است.

## برگشت و حفاظت از وضعیت فعلی

پیش از اجرای انتقال، نسخهٔ قابل بازیابی از تنظیم‌های مؤثر و فهرست شناسه‌های چت ساخته شود؛ صحت نسخه با هش (اثر انگشت فایل) کنترل شود. تنظیم آزمایشی جدا باشد. در صورت شکست، اجرای آزمایشی متوقف و تنظیم قبلی بازگردد؛ گزارش و هزینهٔ شکست حفظ شود. حذف تاریخچه، لغو اشتراک، تغییر حافظه و امضای تراکنش جزو این برنامهٔ پژوهشی نیست.

## وضعیت و کارهای بعدی

| جاری | وضعیت |
|---|---|
| بررسی سیستم و گزینه‌ها | موجودی ریشه و وابستگی‌های نماینده بررسی شد؛ آزمون مدل انجام نشده. |
| تجربهٔ کاربران | در `02-user-experiences.md` جمع‌بندی شده؛ موارد مهم با صفحهٔ اصلی دوباره تطبیق داده شد. |
| تصمیم اجرای آزمایشی | پس از بررسی برنامه؛ حساب و سقف هزینه هنوز انتخاب نشده‌اند. |

فهرست نام پوشه‌ها و نشانگرهای ریشه در `03-directory-inventory.json` ثبت است. فرمان `python3 scripts/check_plan.py --self-test` ساختار بسته و چهار خرابکاری ساختگی را بررسی کرد؛ فرمان `python3 scripts/check_plan.py --ready` با کد خروج ۱ رد شد، چون هر هشت آزمون واقعی اجرا نشده‌اند. دستیار دوم نیز جداگانه حذف شرط، شناسهٔ تکراری، قبولی بی‌شاهد و تغییر محتوای شاهد را آزمود و ردشدنشان را گزارش کرد. این بررسی‌ها فقط کنترل ثبت شواهدند؛ آزمون مهاجرت نیستند.

به‌روزرسانی ۱۹:۱۶ تهران: حبیب آماده‌سازی بدون کلید را خواست و دامنهٔ فعلی را به Claude Code محدود کرد. سقف کل آزمایش ۵ دلار تأیید شده است. آماده‌سازی جداگانه در `claude-api/README.md` آمده؛ اتصال واقعی همچنان انجام نشده. سه موردِ کلید، Codex و سایر هارنس‌ها در `moalagh.md` ثبت شده‌اند.

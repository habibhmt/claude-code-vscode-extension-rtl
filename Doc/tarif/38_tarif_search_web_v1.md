### داکیومنتِ خودِ اوپن کد (حبیب ۰۱:۰۳: «از داکیومنش در بیار»)
`opencode.ai/docs/tools` می‌گوید ابزارهای درونی‌اش `webfetch` و **`websearch`** هستند.
`opencode.ai/docs/websearch` شش پرووایدر می‌دهد:

| پرووایدر | شناسه | کلید | انتخاب |
|---|---|---|---|
| Exa | `exa` | `EXA_API_KEY` | `websearch.provider: "exa"` |
| Firecrawl | `firecrawl` | `FIRECRAWL_API_KEY` | همان کلید |
| Parallel | `parallel` | `PARALLEL_API_KEY` | همان |
| Tavily | `tavily` | `TAVILY_API_KEY` | همان |
| TinyFish | `tinyfish` | «optional» | همان |
| Claude Agent | `claude-agent` | کلیدِ جست‌وجو نمی‌خواهد؛ حسابِ Claude Agent می‌خواهد | فقط دستی انتخاب می‌شود |

- `"provider": "random"` خودکار از پرووایدرهای در دسترس انتخاب می‌کند؛ روی `429` آن پرووایدر تا `Retry-After` (یا ۶۰ ثانیه) سرد می‌شود و `random` سراغِ بعدی می‌رود.
- خاموش‌کردن: `"websearch": false`.
- **تفاوتِ نسخه:** نسخهٔ نصب‌شدهٔ ما (1.14.18) هنوز همان تک‌راهِ Exa-MCP است؛ جدولِ شش‌تایی داکیومنتِ نسخهٔ تازه‌تر است.
